This native Android app, built with Kotlin in Android Studio, helps users study history using flashcards. It asks five true-or-false questions, tracks your answers, and gives personalized feedback at the end.

STEP1 (Welcome Screen):
Displays a welcome message and brief app description.
Includes a "Start" button to initiate the quiz.

STEP2 (Flashcard Question Screen):
Shows one flashcard question at a time with "True" and "False" answer buttons.
Provides immediate feedback after each answer ("Correct!" or "Incorrect").
A "Next" button loads the next question.

STEP3 (Score Screen):
Displays the user's total correct answers.
Offers personalized feedback based on performance.
Includes a "Review" button to go back through the flashcards with correct answers shown.

Development Requirements:
Built using Kotlin in Android Studio.
Utilizes GitHub for version control and GitHub Actions for CI/CD.
Includes well-documented code with comments.
